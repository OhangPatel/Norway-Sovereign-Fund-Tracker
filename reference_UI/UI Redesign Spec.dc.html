UI-ONLY REDESIGN BRIEF · SOVEREIGN INSIGHTS
Restyle the existing app. Do not rebuild it.
Every route, component, prop, handler, data fetch and piece of state stays exactly as it is today. This document changes only what things look like: page background, navbar, cards, type, and a short list of animations. Two themes ship: Light = Olive wash and Dark = Ink field.

01 · RULES OF ENGAGEMENT
What must not change
  • All button behaviour, links, routing, keyboard shortcuts (/ focuses search), sort/filter/compare logic, API calls, and state management.
  • Component tree and DOM structure — restyle in place; no re-parenting, no renaming props, no new libraries.
  • Copy, numbers, labels, and column order stay as-is.
  • The existing logo asset in the project is kept unchanged — same file, same mark. It is only re-mounted in a 26–30px rounded ink tile (radius 8–9px) inside the navbar; do not redraw, recolour, or replace it.
  • Accessibility: keep existing focus outlines, aria labels, and tab order. New hover styles must not remove focus rings.

03 · NAVBAR
Floating card nav with a live ticker band
  • Not full-bleed. The bar floats: 14–18px inset from the page edges, sticky at top, radius 14–16px on the top corners only — the ticker band below it carries the bottom corners, so nav + band read as one card.
  • Height 62–68px. Contents in one flex row, gap 16–20px: logo tile + wordmark (divider hairline after it) · tab group · search (flex:1) · COLUMNS (outline) · COMPARE (ink fill, lime text).
  • Search field: inner tint (#F4F6EA light / #F2EFE4 dark-theme nav), 1px border, radius 10px, mono / key hint at the right.
  • Tabs are mono 11–12px, letter-spacing .1em, uppercase. Active tab sits on a solid lime #D8F34A block (radius 8px); inactive #8A8877.
  • Ticker band: 26–28px tall, one continuous marquee line of the tickers.
  • Same nav in both themes; only the band and surface colours flip.

06 · ANIMATION SET
Seven motions, nothing else
1 · Ticker marquee — single row, translateX 0 → −50% over 22s, linear, infinite (content duplicated once). Pauses on hover.
2 · Total-holdings shimmer — the big figure is a clipped gradient sweeping across the numerals, 5s infinite with a 1s delay. Light theme: lime → white → lime on ink. Dark theme: ink → white → ink on the lime card.
3 · Tab indicator — lime block slides between tabs, 350ms cubic-bezier(.34,1.3,.44,1) on transform + width (slight overshoot).
4 · Nav condense on scroll — past 40px the bar goes 68px → 56px and the ticker band collapses to 0 height, 300–320ms cubic-bezier(.2,.7,.3,1).
5 · Card entry — opacity 0 / translateY 14px → rest, 600ms, staggered 60ms per card, once on mount only.
6 · Card hover — translateY(−4px) + soft shadow, 250ms. Buttons: translateY(−1px). Search: border to ink + 4px lime ring.
7 · Live dot — 6px lime dot pulsing opacity/scale, 1.8s infinite.
All of it honours prefers-reduced-motion: reduce — marquee, shimmer and entry animations stop; hover and indicator transitions drop to 0ms.
